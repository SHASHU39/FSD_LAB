# Assignment 6 — Full Stack MERN Application – CRUD Operations

## Aim
Develop a full stack web application using the MERN stack to perform CRUD operations.

## Structure
- `backend/` — Express server, MongoDB connection, routes, and model.
- `frontend/` — React app using fetch API to communicate with the backend.

## How to run
1. Start MongoDB locally.
2. In `assignment6/backend`, run `npm install` and `npm start`.
3. In `assignment6/frontend`, run `npm install` and `npm run dev`.
4. Open the frontend app and use the UI to add and delete students.

## Summary
This assignment includes a Node/Express backend with MongoDB and a React frontend that performs create, read, and delete operations using REST APIs.
