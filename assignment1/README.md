## Aim
To understand and practice Git fundamentals including local and remote repositories, branching, push, pull, and merge operations by creating and working with a public Git repository.

## GitHub Repository
https://github.com/shashwat-nande/FSD-lab

## Procedure
1. Create a local repository and initialize Git.
2. Add `README.md` and commit the initial files.
3. Add the remote repository with `git remote add origin <REPO_URL>`.
4. Create a `main` branch and push the initial commit.
5. Create a feature branch, add `feature.txt`, commit, and push the branch.
6. Merge `feature-1` back into `main` and push the result.
7. Pull remote changes from `main` to keep the local repository synchronized.

## Files
- `README.md`
- `feature.txt`

## Notes
This assignment demonstrates repository initialization, staging, committing, remote linking, branching, merging, push, and pull operations.
