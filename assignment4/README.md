# Assignment 4 — PHP Server-Side Scripting & MySQL Database Application

## Aim
Write server-side script in PHP to perform form validation and create a database application using PHP and MySQL to perform insert, update, delete and search operations.

## Files
- `db.php`
- `insert.php`
- `update.php`

## Notes
- `db.php` connects to a local MySQL database named `studentdb`.
- `insert.php` inserts a new student record.
- `update.php` updates an existing student record.

## How to run
1. Place these files in a PHP web server folder (e.g. XAMPP `htdocs`).
2. Create a database named `studentdb` and a table `student(id VARCHAR(20) PRIMARY KEY, name VARCHAR(100), email VARCHAR(100), mobile VARCHAR(20));`.
3. Open `insert.php` and `update.php` in the browser to test the forms.
