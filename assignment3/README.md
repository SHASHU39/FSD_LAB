# Assignment 3 — Form Validation using JavaScript

## Aim
To design a user input form and perform client-side validation using JavaScript to ensure correctness and completeness of data before submission.

## Files
- `index.html`
- `style.css`
- `script.js`

## How to run
Open `assignment3/index.html` in a browser.

## Summary
This assignment demonstrates HTML form creation, DOM validation, error message display, and validation logic for name, email, phone, and roll number fields.
