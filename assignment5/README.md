# Assignment 5 — Interactive UI using React

## Aim
Design and develop an interactive user interface using React.

## Files
- `package.json`
- `vite.config.js`
- `index.html`
- `src/main.jsx`
- `src/App.jsx`
- `src/App.css`

## How to run
1. Open a terminal inside `assignment5`.
2. Run `npm install`.
3. Run `npm run dev`.

## Summary
This assignment demonstrates a simple React component with state and event handling. The UI updates in response to button clicks, showing how React renders interactive interfaces.
