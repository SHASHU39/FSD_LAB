# Assignment 2 — Student Portfolio Web Page

## Aim
To design and develop a responsive Student Portfolio web page using HTML5 and CSS3 that displays personal, academic, and project details.

## Files
- `index.html`
- `style.css`

## How to run
Open `assignment2/index.html` in a web browser.

## Summary
This portfolio page uses semantic HTML sections for hero, about, skills, projects, and education. CSS styling includes a dark modern theme, responsive layout, and card-based design.
